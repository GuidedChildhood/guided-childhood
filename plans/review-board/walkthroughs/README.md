# UX walkthrough reports

One file per Wednesday run, named `<YYYY-MM-DD>.md`, written by the weekly UX
walkthrough routine. The shape and the rules are in
`plans/review-board/routines/ux-walkthrough.md`.

The review board's Friday run reads the newest file here as part of its brief.
If this folder holds no report for the past week, the board says the walkthrough
is unknown, not that it passed.

The report of 7 October 2026 was never saved and cannot be recovered.
