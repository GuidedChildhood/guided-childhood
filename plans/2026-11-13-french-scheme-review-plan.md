request, and passes with a warning. The real switch is a repository setting
(Settings, Actions, General, Allow GitHub Actions to create and approve pull
requests), which only Justin can tick.

## Principles worth taking to the digital scheme (not built here)

1. One planned checkpoint per objective per year, everything else formative.
   Our digital record judges any lesson, any time. A checkpoint map for the
   digital scheme is a curriculum decision for Justin, and belongs with the
   once a term review, not a code change.
2. A pupil facing "What I can do" sheet per unit with I've got it, Nearly
   there, Not yet. The digital lessons have no pupil self review sheet.
3. Wall displays per unit. The digital print room has none.
4. Answers beside every printable. Check the digital print room for any sheet
   whose answers are a separate hunt.
5. A games site for home with only what the class has learnt.
