# Ad Library watchlist

Who to check each ad round, and the Meta Ad Library search for each. The
library shows every live Facebook and Instagram ad with its start date. Open
a link, tap an ad, and screenshot it with "Started running on" in view.

The links search by keyword in the UK. If a search brings back the wrong
company, search the brand's page name instead and update the link here.

Why each is on the list is in `briefings/notes/competitor-sightings.md`.
