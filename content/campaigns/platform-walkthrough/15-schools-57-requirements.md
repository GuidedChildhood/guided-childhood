## Post text, LinkedIn (Justin)

The new RSHE guidance has 57 requirements about online life.

It came into force on 1 September. If you lead PSHE, at some point somebody
is going to ask you to show where each one is taught.

I did not want to answer that with a tick list, so the mapping page works
the other way. Every one of the 57 is written out in the guidance's own
words and its own order, with the module that teaches it beside it. And a
requirement only counts as taught if set phrases really appear on that
module's slides. A lesson title is not evidence.

All 57 are taught.

Two things I would want to know if I were you.

It is the online part and no more. The guidance as a whole runs to 195 items
across 28 strands. This is the digital spine that sits inside your PSHE. It
does not replace it.

And the page is open. You do not need a code or a login to read it, check it
or print it for the inspection file.

If you want to see it in a classroom, the pilot is two lessons for a term,
free. No card, no contract, no pupil data.

Links in the first comment.

PSHE leads: how are you evidencing the online requirements this year?
