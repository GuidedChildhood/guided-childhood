privacy level. It does not say which have been spent. This file does.

**Why it exists.** The rule is one scene per post, never invented, never
repeated. A session that cannot see what the last session used will reach for
the same strongest scene every time, and the voice turns into a jingle. A daily
routine reviewing Drive posts will do it faster than a person would.

**The rule.** Before a scene goes in a post, check this list. After it does, add
the row in the same pull request. A scene here is spent unless Justin says it can
run again.

## The other store of scenes, which this ledger cannot see

`content/packs/2026-10-14-reels-story-bank/` holds 24 stories across nine
categories, built in a different session. Nothing in it is recorded here, and
nothing here is recorded there. That is two stores that cannot see each other,
which is exactly the shape of the numbering collision in October, and it will
produce a repeated scene eventually. Whoever next touches either file should
merge them.

Also note that `founding-story.md` is the family voice and `founder-context.md`
is Justin's. A scene can be green in one and wrong in the other, so the level
column says which part of a scene was used where that matters.
